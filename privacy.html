Privacy policy

Family Concierge is a private tool used by two family members. It accesses a dedicated Gmail mailbox to read messages they forward and to mark messages it has handled. It accesses calendars shared with the dedicated Google account to check for duplicates and create events.

Message content is sent to Anthropic's API to identify event details. The resulting events are stored in the family's Google Calendar. Processing records are kept in private family storage, and confirmations are sent through the family's Home Assistant system.

The tool does not sell personal data, use it for advertising, or publish messages or calendar events. Access is limited to the family and the services needed to run the tool. The family can stop using it by revoking the Google account's access and can delete its local processing records.
